# 천경련 디지털 회원명부 v3 (모바일 앱)

천안고 경제인 연합회(천경련) 회원을 위한 휴대폰용 회원명부입니다. 설치비와 서버비가 들지 않습니다.

| 구성 | 사용하는 무료 서비스 | 하는 일 |
|---|---|---|
| 앱 화면 (`site/`) | **GitHub Pages** | 휴대폰 브라우저에서 열고 바탕화면 아이콘으로 설치 |
| 서버 (`backend/`) | **Google Apps Script + 구글 시트 + 구글 드라이브(15GB)** | 회원명부 저장, 신규등록 접수, 명함 OCR, 모임 사진 보관 |
| 명함 인식 | Google 드라이브 OCR → 실패하면 브라우저 Tesseract.js | 명함 사진에서 이름·연락처·주소 자동 입력 |
| 카카오톡 | Kakao JavaScript SDK (무료) | 명함·보고서·안내문을 카톡 친구·단톡방에 보내기 |

## 화면 구성

- **홈(대시보드):** 천안고 브로슈어 디자인(남색·시안, 「함·께·천·고」, 교훈 근면·강직·검소)을 반영했습니다. 회원 수, 기수별·업종별 분포, 추천 성장모델, 공지가 나옵니다.
- **명함첩:** 이름 옆에 「OO회」를 표시합니다. 이름·회사·업종·기수로 검색하고, 기수대와 업종으로 거릅니다. 여러 명을 골라 단체 문자나 카톡을 보낼 수 있습니다.
- **디지털 명함:** 휴대폰, 회사전화, 팩스, 이메일, 주소, 홈페이지 등 명함의 모든 정보를 보여 줍니다. 전화(초록)·문자(파랑)·카톡(노랑)·메일(남색)·연락처 저장(회색) 버튼이 있습니다.
- **기업역량 보고서:** 회원마다 6장면 스토리보드로 구성했습니다. 오프닝 → 사업 소개 → 핵심 강점 → 역량 지표 → 기회와 과제 → 동문 시너지 순서이며, 카톡으로 공유하거나 PDF로 저장할 수 있습니다.
- **성장모델:** Claude 심층분석으로 만든 2~4인 협업 모델 10개입니다. 기업분석, 비즈니스 모델, 수익 시뮬레이션, 로드맵, 정부지원, 리스크, 첫 미팅 의제를 담았습니다. 동문을 2~4명 직접 골라 Claude 분석 요청문을 만드는 기능도 있습니다.
- **신규등록:** 명함을 촬영하거나 사진을 골라 등록합니다. OCR이 항목을 자동으로 채웁니다. 졸업기수(OO회)는 필수이고, 추천으로 가입하면 추천인 이름과 기수를 적습니다. 본인 사진도 올릴 수 있습니다. 신청하면 「승인대기」로 들어가고 총무가 승인합니다.
- **사진첩:** 접근코드를 아는 회원은 누구나 모임 사진을 찍거나 골라 올릴 수 있습니다. 여러 장을 한 번에 올릴 수 있습니다.
- **바탕화면 아이콘:** 안드로이드는 버튼 한 번으로, 아이폰과 삼성 인터넷은 그림 안내에 따라 설치합니다. 카카오톡 안에서 열었으면 다른 브라우저로 여는 방법을 안내합니다.
- **시니어 배려:** 기본 글자 18px, 설정에서 「아주 크게」(20px) 선택, 버튼 높이 54px 이상, 기능마다 고정된 한 가지 색을 씁니다.

## 지금 바로 쓰는 방법 — 초대 링크 (구글 서버 없이)

- 앱 주소: https://tkdcho-ux.github.io/chungyeongryeon-mobile/
- 명부는 접근코드로 암호화한 `site/data.enc.json`으로 올라가 있습니다(AES-256, 코드 없이는 읽을 수 없음).
- 초대 링크 `앱주소#k=접근코드`를 누르면 자동 입장합니다. 접근코드와 단톡방 안내문은 `data/access-code.txt`, `data/초대안내문.txt`(공개 안 됨)에 있습니다.
- 명부를 고친 뒤: `python tools/build_bundle.py` → 커밋·푸시하면 자동 배포됩니다.
- 링크가 밖으로 샜으면: `python tools/build_bundle.py --new`로 코드를 바꾸고 다시 배포한 뒤 새 링크를 공지합니다.
- 이 방식에서는 신규등록·사진이 각 휴대폰에만 저장됩니다(등록은 카톡으로 총무에게 전달). 사진을 모두 함께 보려면 아래 1단계 구글 서버를 연결하세요.

> **카톡으로 HTML 파일을 보내지 마세요.** 파일로 열면(주소창이 `content://`·`file://`) 브라우저가 [현재 페이지 추가]·카메라·글자인식을 막습니다. 회원에게는 항상 위 **초대 링크(https://…)**를 보내세요. 파일로 열린 경우 앱이 「웹 주소로 열기」 버튼을 보여 줍니다.

## 명함 인식 (리멤버 방식)

1. **촬영 틀:** [명함 촬영]을 누르면 카메라 화면에 명함 틀이 나옵니다. 틀에 맞춰 찍으면 명함 부분만 잘라 냅니다.
2. **자동 펴기:** 명함 테두리를 찾아 비스듬한 사진도 반듯하게 폅니다. 사진첩에서 고른 사진은 [모서리 맞추기] 화면에서 네 모서리를 손으로 고칠 수 있습니다.
3. **글자 읽기 (정확도 순서):**
   - **Claude AI (추천):** 서버에 `ANTHROPIC_API_KEY`를 넣으면 AI가 명함을 보고 이름·직위·회사·업종·연락처를 항목별로 채웁니다. 명함 1장에 약 1~2센트가 듭니다.
   - **구글 드라이브 OCR:** 서버만 연결한 경우입니다. 무료이며, 글자를 읽은 뒤 앱이 항목을 나눕니다.
   - **휴대폰 안 Tesseract:** 서버가 없을 때 씁니다. 그림자 제거·대비 보정 후 여러 번 읽어 합칩니다. 굵거나 띄어 쓴 큰 글씨(이름)는 틀릴 수 있으니 하늘색 칸을 꼭 확인하세요.
- **Claude AI 켜는 법:** [console.anthropic.com](https://console.anthropic.com)에서 API 키를 만들고, Apps Script → 프로젝트 설정 → 스크립트 속성에 `ANTHROPIC_API_KEY`를 추가합니다. 모델은 `CLAUDE_MODEL` 속성으로 바꿀 수 있고, 기본값은 `claude-opus-5-5`입니다. 키는 서버에만 두며, 공개 저장소나 `config.js`에 넣지 않습니다.

## 모임 사진 공유·삭제

- **서버 연결 시:** 올린 사진이 구글 드라이브에 저장되어 **모든 회원이 같은 사진**을 봅니다. 긴 변 2048px 고화질로 올라갑니다.
- **서버가 없을 때:** 사진은 올린 휴대폰에만 저장되며, 화면에 그 사실을 안내합니다.
- **삭제:** 사진을 누르고 [사진 삭제]를 누릅니다. 올린 휴대폰이나 관리자 코드를 넣은 휴대폰에서만 보입니다. 서버 사진은 드라이브 휴지통으로 가므로 30일 안에 되살릴 수 있습니다.

## 처음 설치 (총무 1회, 약 20분)

### 1단계 — 무료 서버 만들기 (Google)

1. 총무 구글 계정으로 [새 구글 시트](https://sheets.new)를 만들고 이름을 `천경련 회원명부`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs`의 내용을 모두 지우고 `backend/Code.gs`를 붙여넣습니다.
4. 왼쪽 **프로젝트 설정(톱니)**에서 「편집기에서 appsscript.json 매니페스트 파일 표시」를 켭니다. 그다음 `appsscript.json`에 `backend/appsscript.json` 내용을 붙여넣습니다. 구글 드라이브 OCR 기능이 이 설정으로 켜집니다.
5. 위쪽 함수 선택에서 **setup**을 고르고 **실행**을 누릅니다. 권한 요청이 나오면 허용합니다.
   - 실행 로그에 **회원 접근코드**와 **관리자 코드**가 나옵니다. 따로 적어 두세요.
   - 코드를 바꾸려면 프로젝트 설정 → 스크립트 속성에서 `ACCESS_CODE`, `ADMIN_CODE`를 고칩니다.
6. **배포 → 새 배포 → 유형: 웹 앱**을 고르고, 실행 사용자 **나**, 액세스 권한 **모든 사용자**로 설정한 뒤 배포합니다.
7. 화면에 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 2단계 — 앱 화면 올리기 (GitHub Pages)

1. GitHub에 **공개(Public)** 저장소를 만듭니다. 예: `chungyeongryeon-mobile`. 무료 요금제의 Pages는 공개 저장소만 지원합니다.
   - 저장소에는 화면 코드만 올라갑니다. `.gitignore`가 `data/` 폴더(회원 개인정보)를 제외합니다.
   - 배포할 때 자동 검사가 `site/` 안에 휴대폰 번호가 있는지 확인하고, 있으면 배포를 막습니다.
2. `site/js/config.js`의 `API_URL`에 1단계의 웹 앱 URL을 넣습니다. `APP_URL`에는 배포 주소를 넣습니다.
3. 이 폴더를 저장소에 올리고(push), 저장소 **Settings → Pages → Source: GitHub Actions**를 선택합니다. `.github/workflows/pages.yml`이 자동으로 배포합니다.
4. 배포 주소 예: `https://tkdcho-ux.github.io/chungyeongryeon-mobile/`

### 3단계 — 명부 자료 올리기

1. 휴대폰이나 PC에서 앱을 열고 **설정(톱니)**에 회원 접근코드와 **관리자 코드**를 입력합니다.
2. **관리자 메뉴 → 명부·분석 자료 올리기**에서 이 폴더 `data/`의 세 파일을 고르고 올립니다.
   - `members.json`: 회원 44명
   - `profiles.json`: 기업역량 분석
   - `growth-models.json`: 성장모델 10개
3. 이후 회원 정보는 구글 시트 「회원」 탭에서 직접 고쳐도 되고, 앱 명함 화면의 [회원 정보 수정]을 써도 됩니다.

### 4단계 — 카카오톡 보내기 켜기 (선택, 무료)

1. [Kakao Developers](https://developers.kakao.com)에서 애플리케이션을 추가합니다.
2. **플랫폼 → Web**에 GitHub Pages 도메인(`https://<아이디>.github.io`)을 등록합니다.
3. **앱 키 → JavaScript 키**를 `site/js/config.js`의 `KAKAO_JS_KEY`에 넣습니다.
4. 키가 없어도 동작합니다. 휴대폰 공유창이 열리고 여기서 카카오톡을 고르면 됩니다.
5. 카카오 정책상 웹에서 전화번호로 카톡을 바로 보낼 수는 없습니다. 친구나 채팅방을 골라 보내는 방식입니다.

### 5단계 — 회원에게 알리기

단톡방에 앱 주소와 회원 접근코드를 공유합니다. 앱 홈의 「바탕화면에 아이콘 만들기」를 누르면 설치 방법이 나옵니다.

## 개인정보와 보안

- 회원 연락처는 **구글 시트에만** 있습니다. 앱 화면 파일(GitHub)에는 들어가지 않습니다.
- 명부를 보려면 **회원 접근코드**가 필요하고, 승인·수정·자료 올리기에는 **관리자 코드**가 필요합니다. 접근코드는 회원 전원이 같이 쓰는 코드이므로, 밖으로 새면 스크립트 속성에서 바꾸세요.
- 명함 이미지는 비공개로 저장합니다. 모임 사진과 회원 얼굴 사진은 앱에 보여야 하므로 「링크가 있는 사용자 보기」로 저장합니다. 링크 주소는 추측할 수 없는 형태입니다.
- 신규등록 화면에서 개인정보 수집·이용 동의를 받습니다.

## 데이터 확인이 필요한 항목

명단과 이전 자료가 다른 회원 목록은 개인정보라 `data/데이터_확인사항.md`에 따로 두었습니다(공개 저장소에 올라가지 않음). 관리자 코드를 넣은 기기에서만 명함에 「자료 확인 필요」가 보입니다.

## 폴더 구조

```
site/      앱 화면 (GitHub Pages로 배포)  index.html · css · js · assets · manifest · sw.js
backend/   무료 서버 코드 (Google Apps Script)  Code.gs · appsscript.json
data/      회원명부·분석 원본 JSON (개인정보 — GitHub에 올리지 않음)
docs/      성장모델 심층분석 보고서(.md) · 로고 파일
.github/   GitHub Pages 자동 배포
```

## 내 PC에서 미리 보기

```
python -m http.server 8791
```
브라우저에서 `http://localhost:8791/site/`를 엽니다. 서버 주소가 없으면 `data/` 파일을 읽는 미리보기 모드로 동작합니다.
